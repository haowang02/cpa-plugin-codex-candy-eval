采集模型的回答特征，与正常基准对比，判断模型是否被替换。

查看原理

即使让模型“随便说一个数字或颜色”，不同模型也会呈现不同的回答偏好。重复提问后，这些偏好就形成了可比较的行为“指纹”。

本测试采集多组简短回答，与正常模型的指纹对比，判断是否一致、是否更像其他模型。结果基于统计特征，不能单独证明模型身份或能力。

来源论文：Tomas Bruckner，《One Token Is Enough》（2026）。

通过三次数字生成挑战，识别最接近的模型家族与版本。

查看原理

不同模型生成长整数序列时，会表现出不同的数字偏好与排列特征。本测试自动采集三份回答，提取数字分布和序列特征，与候选模型的指纹对比。

比对时先减弱提示词等环境因素的影响，再汇总三份回答的得分，计算各模型的归因概率。同一家族内各模型的概率之和，即为家族概率。

方法来源：ModelTrace。
